## Data Dictionary

Data from [OpenPowerlifting Data Service](https://openpowerlifting.gitlab.io/opl-csv/introduction.html)

-   **Best3SquatKg** - Best successful squat weight (kg)

-   **Best3BenchKg** - Best successful bench weight (kg)

-   **Best3DeadliftKg** - Best successful deadlift weight (kg)

-   **Sex** - The sex category in which the lifter competed, M, F, or Mx

-   **Age** - The age of the lifter on the start date of the meet, if known

-   **CountryEqualMeet** - Whether the lifter competed in their home country (1 - Yes, 0 - No)

-   **Disqualified** - Whether the lifter was disqualified or not (1 - Yes, 0 - No)
